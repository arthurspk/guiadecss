## :dart: O guia para alavancar a sua carreira

> CSS é a linguagem que dá forma a tudo que você vê na web: layout, cores, tipografia, animações e responsividade. Ela evoluiu muito nos últimos anos — Grid, Flexbox, Container Queries, `@layer`, `:has()` e nesting nativo mudaram a forma de organizar estilos, e hoje CSS resolve sozinho problemas que antes precisavam de JavaScript ou de frameworks pesados. Este guia reúne roadmap, documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas, projetos práticos e comunidades para quem está aprendendo CSS do zero até quem já domina o básico e quer dominar layout moderno e animações. Os recursos em português e gratuitos vêm primeiro em cada seção, e todo link foi verificado. Use-o como apoio para os seus estudos, no seu ritmo.

## 🗺️ Roadmap

- [roadmap.sh — CSS Roadmap](https://roadmap.sh/css) — Roadmap visual e interativo da comunidade: o que estudar em CSS, em que ordem, com links por tópico.
- [roadmap.sh — Frontend Roadmap](https://roadmap.sh/frontend) — O caminho completo de front-end em que o CSS se encaixa, ao lado de HTML, JavaScript e ferramentas de build.
- [MDN — Primeiros passos com o CSS (PT-BR)](https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Core/Styling_basics) — Módulo oficial da Mozilla, em português, do "o que é CSS" até seletores, box model e cascata.
- [web.dev — Learn CSS](https://web.dev/learn/css) — Curso estruturado do time do Chrome, em texto, cobrindo desde seletores até Grid e animações.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Sintaxe e seletores** — regras, propriedades, seletores simples e combinados, especificidade e cascata.
2. **Box model** — `content`, `padding`, `border`, `margin`, `box-sizing` e como o navegador calcula tamanhos.
3. **Cores, tipografia e unidades** — `rem`/`em`/`%`, fontes web, `line-height`, variáveis CSS (`--custom-properties`).
4. **Layout com Flexbox** — eixo principal e transversal, `justify-content`, `align-items`, `flex-grow/shrink/basis`.
5. **Layout com Grid** — `grid-template-columns/rows`, `gap`, áreas nomeadas, `minmax()`, `auto-fit`/`auto-fill`.
6. **Responsividade** — `media queries`, mobile-first, unidades relativas ao viewport, `clamp()` e Container Queries.
7. **CSS moderno** — nesting nativo, `@layer` (cascade layers), `:has()`, `@starting-style`, `view-transitions` e anchor positioning.
8. **Animações e transições** — `transition`, `animation`, `@keyframes`, curvas de easing e `prefers-reduced-motion`.
9. **Organização em projetos reais** — metodologias (BEM, utility-first), pré-processadores (Sass) e frameworks utilitários (Tailwind).

**Por onde começar:**

1. **Entenda o que é CSS** lendo [Primeiros passos com o CSS](https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Core/Styling_basics) na MDN, em português.
2. **Pratique seletores e box model** no [CSS Diner](https://flukeout.github.io/) — jogo que ensina seletores CSS "alimentando" pratos.
3. **Aprenda Flexbox brincando** no [Flexbox Froggy](https://flexboxfroggy.com/) e **Grid brincando** no [Grid Garden](https://cssgridgarden.com/).
4. **Faça um curso completo em português:** o [Curso de HTML5 e CSS3 (Curso em Vídeo)](https://www.cursoemvideo.com/curso/html5-css3/) ou a [apostila gratuita HTML, CSS e JavaScript (Alura/Caelum)](https://www.alura.com.br/apostila-html-css-javascript).
5. **Aprofunde com guias interativos:** o [guia interativo de Flexbox](https://www.joshwcomeau.com/css/interactive-guide-to-flexbox/) e o [guia interativo de Grid](https://www.joshwcomeau.com/css/interactive-guide-to-grid/), do Josh W. Comeau.
6. **Construa projetos pequenos** com o [100 Days of CSS](https://100dayscss.com/) e os [desafios do Frontend Mentor](https://www.frontendmentor.io/).
7. **Teste seu domínio** no [CSS Battle](https://cssbattle.dev/) — recrie designs com o menor código CSS possível.
8. **Publique um projeto no GitHub** a partir de um design do [Frontend Mentor](https://www.frontendmentor.io/) — seu primeiro item de portfólio com CSS de verdade.

Seu primeiro layout em 30 segundos:

```html
<!-- index.html -->
<!doctype html>
<html lang="pt-br">
  <head>
    <meta charset="UTF-8" />
    <link rel="stylesheet" href="estilo.css" />
  </head>
  <body>
    <h1>Olá, Guia Dev Brasil!</h1>
  </body>
</html>
```

```css
/* estilo.css */
body {
  display: grid;
  place-items: center;
  min-height: 100vh;
  font-family: system-ui, sans-serif;
  background: #0f172a;
  color: #f8fafc;
}
```

Abra o `index.html` no navegador — o `display: grid` com `place-items: center` já centraliza o título na tela.

## 📖 Documentação oficial

- [MDN Web Docs — CSS (PT-BR)](https://developer.mozilla.org/pt-BR/docs/Web/CSS) — A documentação de referência do CSS, mantida pela Mozilla, em português.
- [MDN — Referência de propriedades CSS (PT-BR)](https://developer.mozilla.org/pt-BR/docs/Web/CSS/Reference) — Cada propriedade, seletor e função CSS, com sintaxe e exemplos.
- [MDN — Aprenda CSS Layout (PT-BR)](https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Core/CSS_layout) — Módulo completo sobre técnicas de layout: normal flow, Flexbox, Grid e posicionamento.
- [MDN — CSS Grid Layout (PT-BR)](https://developer.mozilla.org/pt-BR/docs/Web/CSS/CSS_grid_layout) — Guia oficial completo do Grid, com todos os subtópicos e exemplos interativos.
- [MDN — CSS Flexible Box Layout (PT-BR)](https://developer.mozilla.org/pt-BR/docs/Web/CSS/CSS_flexible_box_layout) — Guia oficial completo do Flexbox.
- [MDN — CSS Nesting (EN)](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_nesting) — Referência do aninhamento nativo de seletores, suportado por todos os navegadores modernos.
- [MDN — `@layer` (Cascade Layers) (EN)](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer) — Como organizar a ordem de especificidade dos seus estilos com camadas nomeadas.
- [MDN — Container Queries (EN)](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_container_queries) — Responsividade baseada no tamanho do elemento pai, não só da tela.
- [MDN — CSS View Transitions (EN)](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_view_transitions) — API para animar trocas de estado e de página só com CSS.
- [MDN — CSS Anchor Positioning (EN)](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_anchor_positioning) — Nova forma de posicionar elementos (tooltips, popovers) relativos a outro elemento, sem JavaScript.
- [MDN — `@starting-style` (EN)](https://developer.mozilla.org/en-US/docs/Web/CSS/@starting-style) — Define estilos de entrada para animar elementos que aparecem no DOM (`display: none` → visível).
- [CSS-Tricks Almanac](https://css-tricks.com/almanac/) — Referência de todas as propriedades e seletores CSS, com exemplos práticos e comentários da comunidade.
- [Can I use](https://caniuse.com/) — Tabelas de suporte dos navegadores para cada recurso de CSS, atualizadas constantemente.
- [Can I use — CSS Grid](https://caniuse.com/css-grid) — Suporte específico de Grid Layout nos navegadores.
- [CSSWG — Rascunhos das especificações CSS](https://drafts.csswg.org/) — Os documentos oficiais e vivos do W3C CSS Working Group, onde o CSS é definido.
- [CSS Reference (Codrops)](https://cssreference.io/) — Referência visual: cada propriedade CSS com exemplo animado.
- [web.dev — Blog do Chrome sobre a Web](https://web.dev/blog) — Anúncios oficiais de novos recursos CSS suportados no Chrome/Chromium.
- [Chrome Developers — blog](https://developer.chrome.com/blog) — Blog oficial do Chrome DevRel, com posts frequentes sobre CSS moderno.
- [WebKit Blog](https://webkit.org/blog/) — Blog oficial da engine do Safari, com anúncios de suporte a recursos CSS.
- [MDN Blog (EN)](https://developer.mozilla.org/en-US/blog/) — Blog oficial da Mozilla sobre a plataforma web, incluindo novidades de CSS.

## 🤖 IA na prática

CSS é uma das áreas em que a IA mais erra "com confiança": ela sugere propriedades que não existem, hacks antigos para problemas que o CSS moderno resolve nativamente, e prefixos de navegador desnecessários. Use a IA como **acelerador e revisor de layout**, não como fonte de verdade sobre suporte de navegador.

**Para aprender**
- Peça para **explicar um conceito com um exemplo executável**: `justify-content` vs `align-items`, `grid-template-areas`, especificidade da cascata. Cole o exemplo no [StackBlitz](https://stackblitz.com/) ou no [JSFiddle](https://jsfiddle.net/) para ver rodando.
- Cole um layout quebrado e peça: *"por que este elemento não está centralizando e como corrigir com Flexbox ou Grid?"* — depois confirme a resposta no [MDN AI Help](https://developer.mozilla.org/en-US/plus/ai-help), que cita a documentação oficial.
- Peça para **converter um layout antigo** (`float`, `table`, posicionamento absoluto) para Flexbox ou Grid, explicando cada mudança.
- Peça **exercícios com gabarito** sobre o tópico que está estudando (Grid, Container Queries, `clamp()`) e resolva antes de olhar a resposta.

**Para trabalhar**
- Use [GitHub Copilot](https://docs.github.com/pt/copilot), [Cursor](https://cursor.com/), [Claude Code](https://code.claude.com/docs/en/overview) ou [Gemini CLI](https://github.com/google-gemini/gemini-cli) para: gerar variações responsivas de um componente, converter designs do Figma em CSS, escrever animações com `@keyframes` e revisar CSS em pull requests.
- Ferramentas de **design para código** como [v0 (Vercel)](https://v0.app/), [Builder.io](https://www.builder.io/) e [21st.dev](https://21st.dev/) geram componentes com CSS/Tailwind a partir de um prompt ou de um design — ótimas para prototipar, mas sempre revise o CSS gerado antes de usar em produção.
- Depois de **cada** sugestão aceita, teste em telas pequenas e grandes, valide contraste de cor e rode o [validador de CSS](https://www.w3schools.com/css/) mentalmente pelo DevTools — a IA raramente testa responsividade de verdade.
- Peça sempre o contexto de suporte: "preciso que funcione no Safari 16+" muda a resposta (Container Queries, `:has()` e nesting nativo têm suporte recente).

**Limites e boas práticas**
- A IA **inventa propriedades e valores** e mistura sintaxe de versões diferentes do CSS. Confirme sempre na [MDN](https://developer.mozilla.org/pt-BR/docs/Web/CSS) e no [Can I use](https://caniuse.com/).
- Ela tende a sugerir soluções antigas (`float`, hacks de `clearfix`, prefixos `-webkit-`/`-moz-` desnecessários) quando Flexbox, Grid e CSS nativo já resolvem o problema sem gambiarra.
- Peça para **explicar o "porquê"**, não só copiar o código — CSS tem muitas formas de resolver o mesmo problema, e nem todas são a ideal para o seu caso.
- Não cole design proprietário ou tokens de marca de clientes em ferramentas sem a política da sua empresa.
- Entenda o que você aceita: em entrevista e em produção, o CSS é seu — e quem mantém o projeto depois é você.

**Ferramentas de IA para design e CSS:**
- [GitHub Copilot — documentação (PT-BR)](https://docs.github.com/pt/copilot) — Assistente de código integrado ao VS Code; gratuito para estudantes e com plano free limitado.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA para editar, refatorar e conversar com o projeto, incluindo CSS.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: entende o repositório inteiro, incluindo folhas de estilo.
- [Gemini CLI](https://github.com/google-gemini/gemini-cli) — Agente open source do Google no terminal, com cota gratuita generosa.
- [MDN AI Help](https://developer.mozilla.org/en-US/plus/ai-help) — Assistente da MDN que responde citando a própria documentação — reduz invenções sobre CSS.
- [v0 (Vercel)](https://v0.app/) — Gera interfaces com Tailwind/CSS a partir de um prompt — bom para prototipar e para estudar o código gerado.
- [Builder.io](https://www.builder.io/) — Converte designs (inclusive do Figma) em código com CSS/Tailwind.
- [21st.dev](https://21st.dev/) — Biblioteca de componentes de UI geradas com IA, com o CSS/Tailwind pronto para copiar.
- [Galileo AI](https://galileo.ai/) — Gera telas de interface a partir de um prompt, útil para explorar layouts antes de escrever o CSS.
- [Relume](https://relume.io/) — Gera wireframes e componentes de site com IA, exportáveis com estilos prontos.
- [Uilabs](https://uilabs.dev/) — Coleção de componentes de UI abertos, com variações geradas para estudar padrões de CSS.
